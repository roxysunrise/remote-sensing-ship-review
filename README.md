# 遥感船舶检测与人机协同复核系统

面向静态港口遥感影像，实现可靠上传、船舶旋转框检测、大图浏览、人工与 AI 辅助复核、区域统计、版本保存和导出。

当前状态：协作仓库初始化；尚未实现应用、训练模型或部署服务。技术栈尚未确定。

## 协作入口

- [双方协作管理协议](docs/双方协作管理协议.md)
- [模块边界与验收细则](docs/模块边界与验收细则.md)（职责调整提案补充，待双方确认）
- [邀请 B 方与权限管理](docs/邀请B方与权限管理.md)
- [模块交付模板](docs/模块交付模板.md)
- [接口约定目录](contracts/README.md)

本仓库的职责分工：**A 方负责算法与核心技术，B 方负责应用与业务开发**。A 负责检测模型与实验、大图推理、旋转框几何和核心编辑组件、AI 辅助标注计算、任务 Worker、计算运行环境，以及图像验证、存储与上传等底层技术封装和安全评审；B 负责前端页面与集成、常规业务后端、业务数据库、账号项目、影像和任务记录、人工修订历史、统计报告及业务验收。公共接口、权限边界、联调与交付由双方共同确认。具体边界以[双方协作管理协议](docs/双方协作管理协议.md)为准。

## 开发原则

双方可直接开工，不以对方先交 API 为前提。已有接口遵守现有约定；接口缺失时先定义并同步公开，通过 PR 确认后成为共同标准。

建议目录（实现时按需创建）：

```text
backend/                  B：业务 API、权限接入和数据库
algorithm/                A：模型、检测、大图计算、AI辅助与 Worker
components/image-workbench/ A：大图和旋转框编辑核心
frontend/                 B：页面、交互和应用集成
contracts/                双方：接口、数据类型和样例
docs/                     说明、交付与验收记录
tests/                    模块与集成验证
scripts/                  启动、初始化与备份恢复
```

不提交用户影像、完整数据集、模型大文件、运行数据库或认证秘密。项目尚未选择开源许可证；公开、授权和发布需双方另行确认。
