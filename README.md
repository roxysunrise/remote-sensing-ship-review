# 遥感船舶检测与人机协同复核系统

面向静态港口遥感影像，实现可靠上传、船舶旋转框检测、大图浏览、人工与 AI 辅助复核、区域统计、版本保存和导出。

当前状态：后端 `backend/`（业务 40 个端点 + 5 个推理端点）、算法 `algorithm/`
（YOLOv8l-OBB 单图与大图切片）、前端 `frontend/`（登录页、工作台、检测页）均已就位，
可用一条命令在本机跑通「登录 → 上传 → 检测 → 复核 → 统计 → 导出」。
**未合入 main、未部署**；项目训练权重不入库，需自行放置。

一键启动、账号与自检见[快速开始](docs/quickstart.md)：`scripts/start-dev.ps1`。
A/B 交付版本、权重校验与复跑步骤见[联合验收候选基线](docs/validation/ab-acceptance-baseline.md)。

检测模块另有大图推理模式（重叠切片、四点坐标还原、跨片多边形 NMS），见
[检测契约 v0.2](contracts/ship-detection-v0.2.md)；启动、依赖与限制见
[算法模块说明](algorithm/README.md)。

## 开发原则

双方可直接开工，不以对方先交 API 为前提。已有接口遵守现有约定；接口缺失时先定义并同步公开，通过 PR 确认后成为共同标准。

建议目录（实现时按需创建）：

```text
backend/                  A：业务接口、权限和数据库
algorithm/                A：检测、大图计算、AI辅助
components/image-workbench/ A：大图和旋转框编辑核心
frontend/                 B：页面、交互和业务集成
contracts/                双方：接口、数据类型和样例
docs/                     说明、交付与验收记录
tests/                    模块与集成验证
scripts/                  启动、初始化与备份恢复
```

不提交用户影像、完整数据集、模型大文件、运行数据库或认证秘密。项目尚未选择开源许可证；公开、授权和发布需双方另行确认。
