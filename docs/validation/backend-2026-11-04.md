## 契约偏差（实现中已兼容，需 B 方确认）

1. `DetectResponse.frame` 的 schema 要求 `index/time_ms/width/height`，`DETECT_API.md` 示例只写前两个。
   后端按 schema 输出四个字段（多给不少给）。
2. 检测页 `detections[]` 用 `label/score`，主应用结果用 `class_name/confidence`；两套并存，由接口层转换。
3. `DetectionResult.image` 在前端 schema 里指向业务 `Image`（含 `file_url/preview_url`），
   而算法输出是 `file_name/sha256/width/height/mode`；后端返回两者的并集。
