数据模型与数据流

14 张表 · 业务数据库是唯一写入口 · 文件与记录分离 · 版本链保证可追溯

账号与项目

users

id · username · password_hash（PBKDF2）· is_admin · status

sessions

token_hash（只存摘要）· project_id · expires_at · revoked

projects

id · code（PRJ-A-0271）· name

members

project_id + user_id · role（负责人 / 分析员）

users 1—N sessions ｜ users N—N projects（经 members）

影像与任务

uploads

status · stage · chunks_* · expires_at（未完成分片）

images

sha256 · width/height · status · stored_name（内部标识）

tasks

status · attempt · tiles_* · temp_count/final_count · parameters

candidates

image_id · polygon · source · quality · status（AI 候选）

uploads 1—1 images ｜ images 1—N tasks ｜ images 1—N candidates

结果与产物

versions

task_id · label(v0,v1…) · readonly · summary · detections

draft_state / draft_detections

复核工作副本 · review_state · origin（model/manual/ai）

regions

task_id · polygon · counts（中心点落入口径）

exports

version_id · status · files（CSV/JSON/PNG）

events

action（login/task.create/ai.propose/…）· detail · 时间

tasks 1—N versions ｜ versions 1—N exports ｜ tasks 1—1 draft_state

一次任务的数据流

原始影像→ var/blobs→ images 记录→ Worker 逐片推理→ var/results/*.json→ 事务：tasks.done + versions.v0→ draft（复核）→ versions.v1→ exports/*
模型原始结果（v0）不可变：人工修订只写草稿，提交后追加新版本，导出绑定版本号。 删除/过期策略：上传会话 24 h、导出 72 h、过期分片与旧尝试产物在启动时清理； 库与文件的一致性用 python -m backend.tools.fsck 对账（实测 0 问题）。
