系统架构

遥感船舶检测与人机协同复核系统 · 浏览器 → 接口 → 业务后端 → 算法 → 存储（同源部署，单进程）
浏览器前端frontend/ · 原生 JS
login.html登录 / 会话 / 项目选择
index.html 工作台项目·上传·任务·复核·统计·历史·导出
detect.html 检测页图片/视频 · AI 辅助框选
tiles-view.js大图瓦片视口 · 跨块旋转框
▼ HTTP / JSON（同源，无 CORS）
接口层serve.py 反向代理
/api/v1 业务接口 47 条鉴权·项目·上传·影像·任务·草稿·版本·导出·瓦片·账号
/api/v1/vision/* 推理接口 5 条capabilities·sessions·detect·segment·cancel
统一错误信封code / message / details.request_id
▼ 内部调用
业务后端backend/ · FastAPI
api.py业务编排 · 权限校验
security.pyPBKDF2 · 会话 · 限速
jobs.py队列 · 状态机 · 原子发布
storage / imaging私有存储 · 解码预览
geometry / stats复核排序 · 区域计数
ai_assist / ai_planner候选生成 · VLM 门控
tiles.py金字塔 · 按需生成
▼ 检测与几何唯一实现
算法层algorithm/
ship_detector.pyYOLOv8l-OBB 单图推理 · 四点多边形
tiled_inference.py重叠切片 · 坐标还原 · 跨片 IoU 合并
best.pt（不入库）DOTA-v1 训练权重 · SHA256 校验
▼ 读写
存储本地私有
SQLite（14 张表）业务记录是唯一写入口
var/blobs · previews原图与预览，系统内部标识
var/results · exports检测结果与导出产物
表现层 接口层 业务层 算法层 存储层 业务数据库是唯一写入口；Worker 只把结果写到 var/results/，再由 jobs.py 发布为 v0。
