功能流程

一次完整业务闭环：登录 → 上传 → 检测 → 复核 → 统计 → 导出，以及每一步的服务端状态
01

登录进入项目

受控开户的账号登录，服务端按成员关系返回项目空间

POST /auth/login → token
02

可靠上传

分片传输 → 合并 → SHA-256 校验 → 图像验证 → 生成预览

POST /uploads · PUT /chunks · POST /complete
03

创建检测任务

参数在创建时校验；入队后由 Worker 逐片推理

POST /projects/{id}/tasks
04

切片推理

重叠切片、坐标还原、跨片 IoU 合并，进度来自真实分片

GET /tasks/{id}（tiles_done）
05

结果发布

终态与 v0 基线版本同一事务提交，模型原始结果只读

GET /tasks/{id}/result · /versions
06

人工复核

草稿从 v0 加载；确认/改框/补框；AI 候选先预览后确认

GET /draft · PATCH /draft/detections
07

提交版本

带变更摘要追加 v1；空修改拒绝，历史版本只读

POST /tasks/{id}/versions
08

区域统计与导出

中心点落入计数；CSV/JSON/PNG 三格式绑定版本导出

POST /draft/regions · /exports

任务状态机与不变式

queued→ running→ merging→ done cancelled failed （取消在切片边界生效；重启时未完成任务如实标 failed，不假装续算）
done ⇒ final_count 非空且等于结果 count ｜ temp_count 只用于过程展示，不得进统计 ｜ attempt 递增，旧尝试产物可回收 ｜ 终态与 v0 原子提交
异常分支：未就绪影像不能建任务（409 IMAGE_NOT_READY）；空修改提交 409 NOTHING_TO_COMMIT； 并发/队列超限 429 RATE_LIMITED；跨项目一律 403 PROJECT_FORBIDDEN；非法参数 422（创建时即拒绝，不入队）。
