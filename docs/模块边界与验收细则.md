# 模块边界与验收细则

日期：2026-10-27（Asia/Shanghai）。状态：PR #1 的补充提案，随职责协议经双方确认并合入后生效；不是已有实现或测试结果。

本文沿用 PR #1 的分工：A 主责算法、复杂几何、Worker 与基础技术封装；B 主责前端、业务后端和数据库。它与当前 main 中“A 全部后端”的旧约定不同，不因提交本文件自动生效。

## 1. 范围与未决事项

基础范围包含：受控开户及项目隔离、私有持久存储、可恢复上传、RGB PNG/JPEG 校验及预览、真实旋转框检测、全图处理与渐进反馈、手动修订、历史版本、区域统计、导出、资源限制及备份恢复验证。

重点功能包含：疑难目标与无检测区域复核、审核数据导出、点/框提示的 AI 辅助标注。它们不能因“增强功能以后再做”而被悄悄删除。

GeoTIFF/多光谱、局部快检、更多模型与离线微调需另行纳入；视频跟踪、公开注册、复杂审批、高可用集群不在基础范围。

技术栈、具体模型、数值性能目标、文件/像素上限、保留期、备份频率及恢复目标尚待确定。开发者可用记录清楚的临时配置继续开发；涉及对方的公共行为需确认，不能把建议值当成正式承诺。模型选择应记录权重许可及适用数据边界，不承诺未经实测的精度或响应时间。

## 2. 谁拥有数据、谁更新状态

| 对象 | A 主责 | B 主责 / 唯一持久业务入口 |
|---|---|---|
| 账号、成员、项目 | 鉴权机制接入方案及计算/文件边界检查 | 业务 API、数据库、会话及项目授权 |
| 上传与资产 | 传输/存储封装、解码验证、预览产物与处理结果 | 上传会话与资产业务状态、项目归属及查询 |
| 检测任务 | 状态迁移规则、Worker执行及真实进度事件 | 任务与尝试持久记录、条件更新、幂等及查询 |
| 检测原始结果 | 生成、完整性检查、算法元信息 | 结果索引、发布记录及受控读取 |
| 人工修订与审核 | 几何校验、合并及标注转换规则 | 版本存储、冲突检查、审核及审计事件 |
| AI候选 | 生成、有效性与来源说明 | 候选请求业务记录、人工接受及修订写入 |
| 报告与区域 | 空间计算、口径及算法信息 | 区域记录、版本快照、报告生成及下载授权 |

默认由 B 的业务层作为业务数据库唯一写入口。A 的 Worker通过受控内部接口提交事件和产物引用，不直接修改业务表；如选用共享代码中的受控仓储层，须另行记录事务边界，不能形成两套状态存储。

A 自行管理可丢弃的计算缓存及中间产物，但不能把它当成业务记录。A 定义技术状态机，B 审核业务含义并实现持久迁移；双方确认后固化在 contracts，前端不自行推断成功状态。

## 3. 任务的可靠运行

- B 创建任务前检查成员权限、影像就绪和资源政策，持久保存任务后提交调度。数据库成功而入队失败必须可发现、可补偿；由 B 提供派发记录和重试，A 提供幂等执行及 Worker 接入。
- 任务和每次执行尝试分开标识；重复请求或重复消息不创建重复正式结果。重试产生新尝试，旧尝试不能覆盖新结果。
- Worker 上报带任务、尝试和事件顺序/唯一标识；B 拒绝重复、过期和非法迁移。发布最终结果由 B 在校验 A 的完成信息和产物后原子更新业务可见状态。
- 进度来自处理记录，标明阶段及已处理/总切片数；最终合并未完成前数量是临时值。全图覆盖完成和目标检测质量是两种不同证据。
- 取消先进入请求状态，A 在可终止边界停止；B 不能把发出请求当已取消。完成与取消同时发生时，由持久状态的条件更新裁决，只保留一个终态，并在接口约定中记录规则。
- A 提供心跳/执行存活信号，B 识别失联并保留异常记录；不能永久显示运行中。失联不等于进程已停止，重试需要隔离旧尝试并避免资源重复占用。
- 首版可整次重算，不承诺断点续算。重启后能查到状态不等于支持继续计算，验收需分别说明。

## 4. 上传、文件与权限

- A 提供可恢复传输和存储适配、最终长度与校验和验证、真实解码及预览处理；B 提供会话 API、资产记录、权限、额度预留和状态查询。重复完成请求只形成一个正式资产。
- 上传分片成功、文件合并、验证成功、预览完成和可分析分别记录；前端不能把传输100%显示为可检测。
- 文件写入和数据库不能假定共用事务。B 记录待确认/失败状态及对账索引，A 提供存在性校验、清理和补偿操作；双方用故障注入验证孤立文件及缺失文件处理。
- 客户端提交资产标识和提示坐标，不提交服务器任意路径。A 的内部接口不直接对浏览器开放；校验调用身份及项目/任务绑定，不能只信请求携带的 project_id。
- B 在每次业务请求检查权限，A 的瓦片/文件访问封装实施受控读取；账号管理员不默认拥有全部项目影像权限。
- B 执行成员移除与会话撤销，A 的访问封装配合撤权。短期下载链接的到期前有效窗口须明确；需要即时撤权时采用逐请求鉴权读取。
- B 管理回收与引用关系，A 执行受控文件清理。存在任务、结果或报告引用时不能直接删除底层文件；保留期和清理行为在实现前说明。

## 5. 大图和旋转框组件的交付边界

A 交付可嵌入组件及独立演示页，至少支持图像加载、缩放平移、框显示与拾取、列表定位所需方法，以及新增/移动/旋转/调宽高/删除的核心操作和撤销重做。不能仅交付几何函数后将整个编辑器实现留给 B。

B 负责页面布局、工具栏、列表、筛选、快捷键接入与提示、未保存提示、保存请求及错误反馈；不重新实现第二套坐标和框编辑内核。

组件接收影像引用、结果、选中目标、只读/编辑模式；输出选择、视窗及编辑操作事件。具体属性和事件名随实现确定。A 说明组件资源释放、加载/空/失败状态、输入更新策略及撤销边界；B 区分本地未保存操作与服务端持久版本。框架由双方根据可嵌入性确认。

坐标约定必须记录：原点和轴方向、单位、角度单位与正方向、宽高定义、顶点顺序、缩放/裁剪/边界与精度规则；图像预览若旋转或调整尺寸，要有可逆映射。不得由前端根据显示尺寸猜原图坐标。

## 6. 结果、版本、AI候选与统计

- 模型原始预测不可被人工覆盖；B 按 A 的有效结果合并规则保存修订版本，记录操作者、来源和基版本。保存携带基版本，冲突时明确拒绝或另存，不能静默覆盖。
- 手动新增不伪造模型置信度；删除保留追溯记录，历史查看不会改写当前版本。
- AI候选有独立生命周期，绑定资产、提示范围和请求标识。取消或过期请求迟到的结果不自动应用。候选失败可回退手动；轮廓不等于已证明船舶类别。
- 接受候选后由 B 调用正式修订保存流程，执行 A 的几何校验；重复点击接受不得重复新增目标。撤销已保存修订需产生可追溯的新版本，本地撤销不直接删除服务端历史。
- 疑难排序返回原因及依据，不能称为正确概率；目标确认和整图审核分开管理。无检测区域也需提供可记录的检查入口。
- 区域统计必须绑定结果版本。建议采用中心点落入区域规则，边界归属及重叠区域处理写入契约后生效；未确认前不能混用交叠面积等另一种算法。
- 报告绑定不可变结果版本、模型和参数，后续修订不改变旧报告；异步导出应有失败和下载过期反馈。B 生成业务报告，A 提供校验、标注转换及算法指标，不将报告生成全部留给 A。

## 7. 接口和故障的最小交付要求

每个跨界能力随代码交付：正常样例、空结果、错误码与可读信息、输入限制、项目权限、重试/幂等规则、异步状态、版本及依赖说明。错误不返回凭据和内部堆栈；日志以请求/任务标识关联，便于双方定位。

API 参数、坐标、任务/尝试/结果/修订标识统一以 contracts 为准；不得依赖双方口头记忆。前端模拟数据应覆盖真实状态和错误，不只制作成功返回。

发现问题时，报告至少包含提交版本、环境、任务/请求标识、复现步骤、预期和实际结果；不要在 Issue 粘贴认证秘密或无授权影像。

## 8. 验收由谁证明

| 验收项 | A 提供证据 | B 提供证据 | 联合结论 |
|---|---|---|---|
| 检测与大图 | 数据划分、模型版本、精度及接缝/密集样例、坐标验证 | 实际结果展示和目标定位 | 真实全图流程与可解释局限 |
| 上传与权限 | 解码限制、校验、私有文件/瓦片限制 | 续传交互、会话及跨项目直接请求测试 | 未就绪不可检测、只生成一资产 |
| 任务故障 | Worker中断、重复执行、取消边界 | 持久状态、过期事件和发布处理 | 无重复正式结果，状态可恢复 |
| 修订与AI | 几何、候选质量与耗时记录 | 冲突、接受/取消、保存重载及来源 | 候选未接受不计数，版本一致 |
| 统计与导出 | 空间规则和转换验证 | 页面、报告及指定版本快照 | 相同版本与口径结果一致 |
| 备份恢复 | 文件、模型及计算环境恢复说明 | 数据库、索引及业务流程恢复 | 实际重开指定任务和修订版本 |

备份时需记录数据库与文件一致性切点/清单，实际恢复在隔离目录或环境执行，避免覆盖工作数据。A 恢复文件和运行依赖，B 恢复数据库并核对引用，双方确认完整性；只备份数据库不算完成。

验收记录注明硬件、影像规模、并发、提交号、耗时与资源峰值，仅报告已测范围。具体性能阈值和样例清单随模块 Issue 确认；当前没有通过任何性能或恢复验收。

## 9. 需求和分工变化

对新需求记录基础/重点/增强分类、A/B主责、调用关系及验收方法；可以边开发边补充，不要求先设计整个系统 API。模块 Issue 的负责人表示交付主责，协作者仍需提交自己范围的实现。

职责变更、增加必做功能或削减既定范围必须在 PR 中显式说明，并由双方确认。审阅未回复不等于同意；可继续隔离开发，但不能以等待超时单方面改变公共约定。
